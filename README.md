# NLP-Course-Project

This project delves into the world of Natural 
Language Processing (NLP) by building sentiment analysis 
models for Amazon reviews. I explored both traditional 
methods using NLTK and cutting-edge deep learning models 
like RoBERTa that's provided by hugging face. I used two main 
techniques the first one is the older kind of way of 
approaching sentiment analysis with a model called 
VADER(Valence Aware Dictionary and sentiment Reasoner) 
and this uses a bag of words approach and then used a pre
trained model from hugging face that's a roberta type model 
and this is a more advanced transformer model and I 
compared results between these two models and then I 
explored a hugging face pipeline. Through a comparative 
analysis, we gain a deeper understanding of NLP techniques 
for sentiment classification.
